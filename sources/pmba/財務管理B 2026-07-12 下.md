# 07-12 課程摘要：財報分析、企業評價與投資案評估

## 1) 🎯 本次學習快照（30 秒看懂）
- **課程／章節**：PMBA 財報分析／財務管理（廖咸興教授）線上課程；企業評價、財務比率、信用風險、現金流折現、投資案評估與 Seagate／Veritas 個案

  - 折現率／要求報酬率（Discount Rate / Required Return）
  - 淨現值（Net Present Value, NPV）
  - 內部報酬率（Internal Rate of Return, IRR）
  - 股權現金流量（Equity Cash Flow）

## 2) 🧠 核心概念與框架（Concepts → Structure）
- **框架 / 模型 1：企業評價與市場乘數法**
  1. 找真正可比的同產業／同業務公司。
  2. 排除分母為負或沒有經濟意義的倍數，例如負 EPS、負 EBITDA、負營運現金流。
  3. 用可比公司的 P/E、P/CF、EV/EBITDA 等市場倍數。
  4. 套用到目標公司的盈餘、現金流或 EBITDA。
  5. 推估營運資產或股權價值。
- **框架 / 模型 2：財務比率與信用風險分析**
  1. 比率沒有單一 optimal value，要看產業、同業與趨勢。
  2. 信用風險較重視利息保障倍數、營運現金流／總負債、流動性與 Z-score。
  3. D/A、TD/Capital、固定資產週轉率等在部分情境資訊內涵不足。
  4. Altman Z-score 可用來排序，但不宜機械套用 1968 年臨界值。
  5. 景氣反轉時的穩定性，比景氣好時的漂亮數字更能看出公司體質。
- **框架 / 模型 3：現金流折現與時間價值**
  1. 估計未來現金流。
  2. 判斷現金流風險。
  3. 用反映風險的折現率 (r) 折回現在。
  4. 得到現值。
  5. 與現在投入成本比較，判斷是否划算。
- **框架 / 模型 4：投資案評估的口徑一致性**
  1. 若 CF0 是整體投資額，後續要用 project cash flow，折現率用 RA。
  2. 若 CF0 是股東投入額，後續要用 equity cash flow，折現率用 RE。
  3. 有扣利息／還本後的現金流，多半是股權現金流。
  4. 沒扣利息的現金流，偏計畫／資產現金流。
  5. NPV、IRR 都要判斷算出來的是資產報酬還是股權報酬。
- **重要定義**
  - **本益比 10 倍**：市場願意為每 1 元 EPS 給 10 元股價估值，而不只是「股價除以 EPS」。
  - **EBITDA**：營業利益加回折舊與攤銷，可作為營運現金流 proxy，但不等於自由現金流。
  - **要求報酬率／資金成本**：同一筆資金從投資人角度叫要求報酬率，從公司角度叫資金成本。
  - **NPV**：將整個評估期間所有現金流入與流出折現加總；NPV &gt; 0 才代表價值增加。
  - **回收期**：不只是多久回本，也是一個風險控制工具；環境越不穩定，可接受回收期越短。
  - **投資等級**：Triple B 不論 plus/minus 或 outlook，仍屬投資等級；Double B 以下不是投資等級。
- **常見混淆點**
  - 容易搞錯的是：把不同風險的收入與支出混成 net cash flow 後用同一折現率；若風險差異重大，應分開折現。
  - 容易搞錯的是：投資報酬率 15% 聽起來高就代表好；正確做法是與相同風險市場資產的要求報酬率比較。
  - 容易搞錯的是：CF0 用整體投資額，後續卻用扣利息後的股權現金流，或 RA／RE 混用。
  - 容易搞錯的是：負 EPS、負 EBITDA 公司仍可直接拿來算 P/E 或 EV/EBITDA；這些倍數通常沒有正常經濟意義。

## 3) 📌 例子與公式（Examples / Equations / How-to）
- **代表性例子 1：Seagate／Veritas／Hardy 個案**
  - 情境：Seagate 市值甚至低於其持有 Veritas 約 40% 股權的市值，導致市場看起來像把 Seagate 的 Hardy／磁電機營運資產估成負值。
  - 套用觀念：
    1. 若營運資產仍能創造正營運現金流，價值不應為負。
    2. 用 P/E、P/CF、EBITDA 等可比公司倍數估 Hardy／磁電機營運資產價值。
    3. 第一階段賣掉營運資產以 unloSeagate value。
    4. 第二階段透過 Veritas 股權交換處理資本利得稅與清理資產組合。
    5. 最後 Seagate 主要剩現金與股票，市場較容易評價。
- **代表性例子 2：固定成長股利評價**
  - 情境：預期下年度股利為 1.3，股利每年永續成長 5%，折現率 (r = 10%)。
  - 計算：(1.3 / (0.1 - 0.05) = 26)
  - 解讀：股票價值為 26 元。
  - 延伸：若市場因公司與 AI 產業連結而把成長率預期從 5% 改為 8%，價值會上升；但成長率提高通常也代表風險與要求報酬率提高。
- **代表性例子 3：房貸等額攤還**
  - 情境：貸款 12 萬，10 年，年利率 12%，每月等額攤還。
  - 輸入：120,000；120 個月；月利率 1%。
  - 計算：年金現值因子約 69.79；每月付款約 1,720／1,722。
  - 解讀：每月付約 1,722，付 120 個月，可還清貸款。
- **代表性例子 4：投資案口徑一致性**
  - 情境：投資計畫資產 100、負債 40、股權 60。
  - 若算計畫／資產 NPV：
    - CF0 = -100
    - 後續用 project cash flow
    - 不扣利息
    - 折現率用 RA
  - 若算股權 NPV：
    - CF0 = -60
    - 後續用 equity cash flow
    - 扣掉債權人本息後看股東剩餘現金流
    - 折現率用 RE
- **公式或計算步驟**
  - **P/E Ratio**
    - 輸入：股價、EPS
    - 計算：股價 ÷ EPS
    - 解讀：市場對每 1 元 EPS 給多少倍估值。
  - **P/CF Ratio**
    - 輸入：股價、每股營運現金流量
    - 計算：股價 ÷ 每股營運現金流量
    - 解讀：市場對每 1 元營運現金流量給多少倍估值。
  - **EBITDA**
    - 輸入：營業利益、折舊、攤銷
    - 計算：營業利益 + 折舊 + 攤銷
    - 解讀：營運現金流能力的 proxy。
  - **無窮年金現值**
    - 輸入：每年固定拿 A，折現率 r
    - 計算：(PV = A / r)
    - 解讀：每年固定拿 A、拿到永遠的現值。
  - **固定成長永續現金流**
    - 輸入：第一期現金流 C、折現率 r、成長率 g
    - 計算：(PV = C / (r-g))
    - 解讀：固定成長永續現金流的現值。
  - **附息債券價值**
    - 輸入：票息 C、面額 F、期數、折現率 r
    - 計算：票息 C 的年金現值 + 面額 F 的折現值
    - 解讀：普通附息債券就是「票息年金 + 面額折現」。
  - **NPV**
    - 輸入：第 0 期投資、各期現金流、折現率
    - 計算：所有現金流折現後加總
    - 解讀：NPV &gt; 0 增加價值；NPV = 0 沒增加價值；NPV &lt; 0 更差。
  - **回收期**
    - 輸入：初始投資、各期現金回收
    - 計算：累計現金流直到 cover 初始投入
    - 解讀：越早回收，承擔未來不確定性的期間越短。
- **判讀口訣**
  - 看到負 EPS／負 EBITDA → 不要硬算 P/E／EV/EBITDA。
  - 看到未來現金流 → 先問風險多大、折現率 r 多高。
  - 看到公司說投資報酬率很高 → 先問相同風險市場報酬率是多少。
  - 看到 CF0 = 整體投資額 → project cash flow + RA。
  - 看到 CF0 = 股東投入額 → equity cash flow + RE。
  - 看到回收期 → 先問設定年限是多少。
  - 看到債券 → 拆成票息年金與面額折現。

## 4) 🧪 可能考點（Exam hooks）
- **高機率考點**
  1. 為什麼負 EPS、負 EBITDA 或負營運現金流公司不適合直接作為 P/E、P/CF、EV/EBITDA 倍數基準。
  2. 如何分辨 project cash flow 與 equity cash flow，以及 RA／RE、CF0 是否配對正確。
  3. 為什麼不同風險的現金流不應直接加總後用同一折現率折現。
  4. 要求報酬率與資金成本為何是同一概念的不同角度。
  5. 回收期如何作為風險控管工具，並影響 NPV／IRR 的分析期間 (N)。
  6. Altman Z-score、利息保障倍數、營運現金流／總負債如何用於信用風險排序。
  7. Seagate 個案為什麼分成「賣營運資產」與「Veritas 股權交換」兩階段。
- **容易出陷阱**
  - 錯誤直覺：本益比只是股價除以 EPS。
    正確做法：要說出經濟意義——市場對每 1 元 EPS 給多少估值。
  - 錯誤直覺：15% 投資報酬率一定好。
    正確做法：若相同風險市場資產可賺 18%，15% 反而不創造價值。
  - 錯誤直覺：CF0 = -100 時後續現金流可以扣利息。
    正確做法：CF0 是整體投資額時，應用資產／計畫現金流，不扣利息，折現率用 RA。
  - 錯誤直覺：Triple B 加減號或 outlook 不同就可能不是投資等級。
    正確做法：只要是 Triple B，仍是投資等級；Double B 以下才不是。
  - 錯誤直覺：回收期 29 年比 31 年短，所以必選 29 年。
    正確做法：若兩者都超過設定年限，可能兩個都不選。

## 6) 📋 完整知識點索引（Coverage index，寧多勿漏）
### A. 償債支出與財報揭露限制
- 當期銀行要還多少本金，通常財報上直接看不到。
- 財報可以 roughly 估償債支出，但不完全準確。
- 長期負債減少不一定等於當期還本。
- 負債減少中間可能同時有再借款。
- 財報上看到的長期負債變動可能只是淨額。
- 若今年有較大還債金額，通常貸款契約或相關揭露會出現。
- 每年要還多少本金是重要資訊。
- 銀行端一定知道借款人每年要還多少，因為銀行掌握貸款契約與還款排程。
- 從銀行角度看，償債支出一定要算。
- 從財報角度看，直接找出當期償債支出不一定抓得到。
- 若不知道今年新借多少與還多少，只看到的是淨額。
- 教授稱讚非財會背景同學提出好問題。
- 有會計知識者可能習慣財報呈現方式，反而不一定意識到使用者想取得償債支出資訊。
### B. 現金基礎保障倍數
- 若分母是利息費用，且為現金基礎，則是現金基礎利息保障倍數。
- 若分母是償債支出，則是現金基礎償債支出保障倍數。
- 教授用灰色與藍色區分兩個現金基礎比例（投影片顏色資訊）。
- 有些公司會揭露償債支出相關資料。
- 有些報表會揭露償債支出。
- TEJ 可能直接提供相關資料欄位或下載項目。
- 若 TEJ 沒有該欄位，沒有就沒有，需要接受資料限制。
### C. 市場基本面比例／市場乘數法
- 市場基本面比例中的「市場」是 market price，也就是價格。
- 使用市場乘數法時，參考物件必須在市場上找得到價格。
- 若市場上沒有類似標的，就很難用市場乘數法。
- 本次個案市場上類似標的不好找，因此方法使用上有困難。
- 市場乘數法是用市場上同產業公司的比例作為估值基準。
- 理論上，同一市場、同一產業，對每 1 元 EPS、每 1 元營運現金流量、每 1 元淨值、每 1 元營收的估值應該差不多。
- 找到目前市場有交易的同產業公司，就可用其市場比例作為 benchmark。
- 負值公司用某些倍數會沒有意義。
- 製造業使用淨值作為評價基礎不那麼重要，因為淨值是歷史成本。
- 金融業有時反而會看淨值相關倍數。
- 不同產業適用的市場乘數不同。
- Seagate 是製造業，因此淨值相關倍數沒那麼重要。
- 營收不代表獲利，也不代表賺錢。
- 教授建議 Seagate 個案用盈餘與營運現金流量兩個指標為主。
- 下方例子全部都算，是為了示範如何找 benchmark。
- 可比公司必須是同產業、規模與業務相近。
- 拿不一樣業務的公司比較，是「驢跟馬」「指鹿為馬」。
- 同產業其他公司都上去而某家公司還沒漲，可能有補漲概念。
- Revenue 倍數常用於淨值為負、營運現金流為負的公司。
- Revenue 最小不會是負的。
- Revenue 倍數在網路泡沫時期出現。
- 網路泡沫時很多公司還在燒錢、賠錢，但多少有點價值。
- 若連價值都沒有，老師稱為「本夢比」。
- 財務人無法接受只看夢，至少要有成長率。
- 若成長率也是負的，財務人難以接受。
- 簡易評價不是不尊重時間，而是 CEO 要簡單的東西。
- 複雜東西留給專業人員處理。
- 做大案子時通常先用簡單方法看看。
### D. Seagate 個案：背景、估值目的與市場錯價
- 個案要評估的是 Seagate 的磁電機事業／Hardy 營運資產價值。
- 個案不是評估 Seagate 公司整體價值。
- Seagate 要把磁電機事業賣掉，因此需要估其價值。
- 要賣一個資產，總要知道它值多少錢。
- 估值目的在於決定營運資產應賣多少價格。
- Seagate 股價已經失真或不對。
- 整個 Seagate 的價值包含本身磁電機／Hardy 事業，也包含子公司 Veritas 股票價值。
- Seagate 持有 Veritas 約 40%。
- 問題是 Veritas 40% 的市價比整個 Seagate 市價還大。
- 若用市場市值推回來，會像是 Seagate 磁電機／Hardy 事業價值為負。
- 教授認為磁電機事業價值為負「是可忍孰不可忍」。
- Seagate 磁電機事業本身可以創造正的現金流。
- 營運現金流量應來自磁電機事業，其他投資性項目不屬於營運。
- 會產生正營運現金流量的資產，不可能價值是負。
- 個案基本概念是把公司價值還給股東。
- 最簡單的方法是把被低估的東西賣掉。
- 人家看到會產生現金流的東西，當然會用正價值購買。
- 把磁電機／Hardy 事業賣掉、轉為現金流入，可以實現股東價值。
- 從 Seagate 市價或市值看，磁電機／Hardy 事業顯然被低估，甚至被低估到負值。
- 將營運事業出售是讓價值顯現的做法。
- Seagate 個案整個過程就是賣，只是賣的方法更複雜。
- UnloSeagate value 最簡單的方法就是把它賣掉，賣掉後現金進來。
- 新 CEO 目的不論動機如何，總之是要讓股東開心。
- Seagate 股價乘上股數比其子公司 Veritas 股價市值還低。
- 即使扣掉稅，Seagate 市值仍低於 Veritas 市值。
- 若當時是 Seagate 股東，會非常不爽。
### E. Seagate 個案：可比較公司與倍數資料

### F. 本益比、P/CF、EBITDA 與估值倍數經濟意義
- 教授問：「本益比 10 是什麼？」
- 不要只回答「股價是 EPS 的 10 倍」。
- 本益比經濟意義是市場對每 1 元 EPS 的估值。
- 本益比 10 倍，表示有 1 元 EPS，市場給 10 元股價。
- 本益比 20 倍，表示有 1 元 EPS，市場給 20 元股價。
- 本益比 30 倍，表示有 1 元 EPS，市場給 30 元股價。
- 市場乘數反映市場對公司每 1 元績效指標的估值。
- P/CF 是市場對每 1 元每股營運現金流量給多少估值。
- 這些比例都是股價除以每股指標，觀察市場給幾倍。
- 本益比可用來判斷股價相對高估或低估。
- 同產業、全球化市場下，可用 AI 相關股票或同類公司作估值比較。
- 若台灣同類股票估值明顯高於 NVIDIA、三星、海力士等公司，可能顯示估值偏高或泡沫。
- 若台灣估值較低，代表可能還有上漲空間。
- 教授提醒不直接說市場高低，避免擾亂市場，但學習重點是自行判斷高估或低估。
- 若本益比 20–30，還在教授想像範圍。
- 若本益比 100，教授認為很奇怪。
- 比較同產業股票估值是否高估或低估，一比就知道。
- 同樣型別公司的股票估值可作相互參考。
- 教授提到還沒正式講營運現金流，但可用 EBITDA。
- EBITDA 是營業淨利／營業利益再把折舊攤銷加回去。
- 兩家可比較公司 EBITDA 是負的。
- 兩家可比較公司淨利是負的。
- 兩家可比較公司 EPS 是負的。
- EPS 為負時，本益比計算或解讀失去正常意義。
- 營運現金流為負時，P/CF 比較意義受限。
- EBITDA 不是精準 free cash flow，只是 proxy。
- 銷管費用、銷貨成本、收入也可能有應計事項。
- 若要真正嚴謹計算，要算 free cash flow。
- Free cash flow 後面會講。

### H. 財務比例分析：沒有單一最佳值
- 財務比例通常沒有明確 optimal value。
- 財務比例常說越大越好或越小越好，但仍要看比較基準。
- 判斷財務比例要根據產業。
- 可以跟產業同業比較。
- 可以找幾個與公司比較像的同業，比較自己比它好或差。
- 也可以看趨勢。
- 財報分析至少做五年分析。
- 若公司只成立三年或上市三年，就看三年。
- 可行的話，五年是標準。
- 時間太長沒有意義，因為產業變化大，太久以前不重要。
- 五年用來看 trend 是往好或往壞。
- 除了看自己的趨勢，也要看同業趨勢。
- 若自己每年成長 5%、7%，但同業成長 30%，自己的表現未必好。
- 若自己每年下滑 5%，但同業每年下滑 50%，自己反而相對好。
- 看公司一定要跟同類型公司或產業比較。
- 景氣有上行與下行。
- 景氣下行時，要看誰跌得比較慢。
- 景氣上行時，要看誰爬升得比較快。

### I. 信用評等與信用風險
- 預測債信比／債信評級可用類似方式分析。
- 可以推估公司目前信用風險狀態。
- 信用風險狀態通常用信評表示。
- Triple A 是最好。
- 信評等級包含 Triple A、Double A、Single A、Triple B。
- 只要看到 Triple B，不管加號、減號或沒有號，都是投資等級。
- Triple B 後面可能有 plus/minus。
- 信評後面還有 outlook，用來看未來趨勢。
- Outlook 可能是正向或負向。
- 只要是 Triple B，仍是投資等級。
- Triple B 以下到 Double B 之後，就不是投資等級。
- 投資等級與非投資等級的債務資金成本差異非常大。
- 公司基本上要想辦法維持在投資級以上。
- 可以預測別人的債信，也可以預測自己的債信。
- 公司也可以預測自己的信用趨勢。
- 找信評公司評等非常貴。
- 企業可用財報自行估策略夥伴、供應商、顧客的信用風險。
- 不能要求供應商或顧客為了交易而花大量費用去做信評。
- 若有對方財報，就可以自己估對方信用值。
- 估信用值後，可決定對方屬於最好等級或中間等級。
- 不同信用等級可給不同交易信用額度。
- 信用好的客戶可給較長付款展延，例如五個月展延（後文未完）。
- 專業信用評等可以找信評公司做，但成本很高。
- 通常很少同時找不同評等機構，因為每找一家要花幾十萬美金。
- 除非很大的併購案，有兩個競爭者在做，才可能出現多家評等。
- 評等通常不會差很多。
- 評等公司評等非常精確，score 很準，定義也很精確。
- 評等中的「機械部分」很準。
- 另一部分要看人。
- 評等公司會與主管訪談，觀察眼神是否飄忽。
- 評等公司會去工廠看看。
- 評等機構強調質化分析。
- 課堂多數財務分析工具屬於量化、機械式分析。
- 質化分析會看專業技能。
### J. 交易對手風險與長期策略關係
- 建立稍微長期一點的關係時，需要知道對方是否能持續存活。
- 與供應商簽三年約，若供應商兩年後倒閉，第三年就會出問題。
- 客戶也一樣，只要涉及策略性關係，都需要了解對方財務狀況。
- 策略性關係意味著長期關係，因此要評估 counterparty condition。
- Counterparty 是交易或合約中的對方，不一定是壞人或敵人。
- 教授用結婚比喻：選長期對象時，會想知道對方是否穩定。
- 公司做大型資本支出並舉債，資本結構可能改變。
- 資本結構改變可能導致信用評等被調降。
- 信用評等被調降會使資金成本變高。
- 若資金成本可能上升，公司要重新考慮是否執行資本支出。
- 教授提供研究報告／paper 整理的信評參考資料。
- 該研究整理 S&P 評等公司資料，用各評等公司財務比率中位數比較。
- S&P 是全球前兩大信用評等公司之一。
- AAA 公司利息保障倍數中位數約 11.8 倍以上。
- AAA 公司營運現金流量約為總負債的 82.3%。
- 營運現金流量／總負債 82.3% 表示一年營運現金流約可償還總負債八成。
- 評等越差，利息保障倍數越低。
- 從投資等級掉到非投資等級，舉債資金成本會非常高。
### K. 信評指標資訊內涵
- D/A 指標可能不好用。
- 若兩家公司做一樣事情、買一樣機器，但資產帳面基礎不同，D/A 可能造成誤判。
- D/A 可能因資產衡量問題導致評價差異，雖然經濟實質相同。
- TD 指長債相關比率。
- 債務裡有短債與長債。
- 長債是一年以上的債務。
- 一年以上的長期資金稱為 capital。
- Capital 等於長債加上 equity。
- TD/Capital 表示長期資金中負債所占比例。
- 長期資金中負債比例越高，信用評等通常越差。
- Liquidity 被教授說明為 Asset 減掉 Liability。
- 某些 liquidity 指標也會因資產衡量問題而失真。
- 教授認為某些比例不好，會誤判。
- 利息保障倍數是比較 OK 的指標。
- 營運現金流量／總負債也是比較 OK 的指標。
- 總負債「欠人家多少錢」通常比較正確，除非負債有隱藏或未呈現問題。
- 負債金額相對不容易失真。
- 分析時要判斷資料的資訊內涵（information content）。
- 若一個指標沒有資訊內涵，就是不 informative。
- 有些指標甚至可能提供 negative 的資訊，因此不應使用。
- 教授認為前面兩個指標較有用。
- 第一個有流量資料，比較安全。
- TD 雖然是存量，但總負債比較不會失真。
### L. Altman Z-score
- 教授介紹免費模型 Altman Z-score。
- 較好的信用風險模型通常要付費。
- Altman Z-score 是用多個比例加權平均算出 Z 值。
- Working Capital / Total Assets 是 Altman Z-score 的一項。
- Working Capital 是流動資產減流動負債。
- Working Capital 越大，公司發生支付不能的機會較少。
- 財務危機可理解為支付不能。
- Retained Earnings / Total Assets 是 Altman Z-score 的一項。
- 保留盈餘代表過去賺的錢沒有發掉。
- 保留盈餘越大，表示過去多賺錢且沒有花出去，是好事。
- 教授用「月光族」比喻保留盈餘低是不好的。
- EBIT / Total Assets 是 Altman Z-score 的一項。
- EBIT 是稅前息前、營業利益。
- EBIT / Total Assets 越大越好，表示當期營業上賺錢。
- Sales / Total Assets 是 Altman Z-score 的一項。
- Sales / Total Assets 越大越好，表示資產創造營業額能力較好。
- Market Value of Equity / Book Value of Total Liabilities 是 Altman Z-score 中唯一分母不同的項目。
- 權益市價除以帳面總負債越大越好。
- 權益市價／帳面總負債變大可能因借錢少或市值高。
- 借錢少代表較不容易破產。
- 股價高、市值高代表市場喜歡公司。
- Altman Z-score 每個組成項目都是越大越好。
- Z 值越大，公司越安全。
- Z 值越小，公司越危險。
- Altman Z-score 原始研究根據三年內到五年內是否違約或破產的資料。
- Altman Z-score 原始年份是 1968 年。
- 1968 年距今很久，環境不同，因此原始臨界值參考性有限。
- Z-score 本身數字越大越好沒有問題。
- 若找五家公司要挑前兩家，可用 Z-score 做 ranking 排序。
- 不應機械式說低於 1.8 就一定不行。
- 1.8 這類 benchmark／臨界值已不一定適用。
- 不同產業與時代下，Z-score 臨界值可能不同。
- Z-score 機率或分數越大越好，這點沒有疑義。
### M. 財報比率分析限制
- 比率分析沒有完整理論基礎。
- 除了存貨可能有理論 optimal，其他多數比率只能說大概方向。
- 存貨 optimal 需看買哪種東西，可以解出最適值。
- 其他比率常只能說大於某數比小於某數好，缺乏理論最適值。
- 因缺乏理論，只能拿產業平均參考。
- 使用產業平均不是很學術，只能提供大概方向。
- 產業間差別很大。
- 公司若多角化，難判斷到底屬於哪一種產業。
- 實務上找同產業 benchmark 很困難。
- 研究上可將每個部門 sales 加總後處理，但實務上通常沒有人幫你做。
- Benchmark 本身要找到正確對象就很困難。
- 教授以 SpaceX 上市估值作為難找可比公司的例子。
- 會計準則差異會影響比較。
- 臺灣與美國會計準則可能不同。
- 每個國家準則差異都可能不一樣。
- 跨國選供應商、顧客、通路時，比較財報會遇到不同經濟體會計準則差異。
- 不同會計方法也會影響比較。
- 存貨計價方法不同會影響財報比率。
- 折舊方法不同會影響財報比率。
- 會計年度不同也會影響比較。
- Seagate 會計年度到六月。
- 美國公司可能以 6 月 30 日為年度結束、7 月 1 日為新年度開始。
- Fiscal year 指財政年度。
- Calendar year 指日曆年度。
- 日本會計年度常從 4 月 1 日開始。
- 臺灣通常從 1 月 1 日開始。
- 比較一家到六月底、一家到十二月底的財報，會有困擾。
- 做跨公司比較時要注意會計年度因素。
### N. 特殊事件與趨勢分析
- 趨勢存在的前提是公司現狀沒有改變。
- 若中間發生結構性改變，原本趨勢可能失效。
- 常見特殊事件之一是管理階層改變。
- 管理階層改變可能讓公司決策風格不同。
- 管理有 style，有些人積極，有些人被動。

### S. 現金流評價核心與時間價值
- 現金流評價是財務核心。
- 此處只教方法概念。
- 後面真正核心包含現金流評價與折現率估計。
- 本節是假設現金流與折現率都知道，問現在值多少錢。
- 後面會做兩個非常簡單的應用，用在債券評價。
- 前面使用現金流評價主要目的在做價值評估。
- 基本上是在算營運價值。
- 重置價值不管未來。
- 帳面價值就是帳面。
- 課程 evaluation 基本核心是做營運價值分析。
- 前面算 Seagate 機器價值，也是在算營運價值。
- 不是算機器作為資產賣掉值多少。
- 是算它產生的營運現金流量相當於多少價值。
- 大部分情況都在算營運價值。
- 看到現金流量，如何估計它的現在價值。
- 未來現金流量如何算現值，現值就是它值多少錢。
- 未來有時間差，明年 100 萬、後年 100 萬、大後年 100 萬時間軸不同。
- 不同時間進來的錢，現在價值不一樣。
- 時間造成的價值差異就是時間價值。
- 明年進來 100 萬與現在給 100 萬，選現在。
- 現在拿 100 萬放銀行，明年可能變 101 萬或 102 萬。
- 越早拿到的錢越有價值。
- 財務世界裡，時間軸上的 cash flow 是可以移動的。
- 現在給 100 萬，等於明年給 101 萬（依利率概念）。
- 移動靠利率。
- 現金流往現在移是折現。
- 往現在移，價值會變小。
- 現在價值高於未來價值，未來價值換到現在會變低。
- 因為中間有時間差，資金放著會長利息。
- 現金流往後移動是複利 compounding。
- 中文前後容易混淆，英文 baSeagateward、forward 比較準確。
- 現金流可以 forward / baSeagateward 移動。
- 現金流移動關鍵是 r。
- r 反映現金流量風險。
- 風險越大，r 越大。
- 高風險資產要求高報酬率。
- 未來一筆錢風險很大，其現值會低。
- Discount rate 的 r 越大，現值越低。
- 不要以為 r 是從天上掉下來的。
- 高風險與低風險公司承諾同樣 cash flow，折現率不同。
- 高風險公司折現率較大，低風險公司折現率較小。
- 高風險公司一年後承諾一筆錢，現值會比較低。
- r 名稱很多。
- 最中性名稱是利率。
- r 可稱為折現率。
- r 可稱為複利率。
- r 可稱為要求報酬率。
- r 可稱為資金成本。
- 這些名稱都在講 cash flow forward / baSeagateward 移動。
- 要求報酬率是投資人角度。
- 資金成本是接受錢的人／接受資金者角度。
- 若投資人投資新創公司，因風險高，公司必須付高一點資金成本。
### T. 融資決策、發債發股與投資本質
- 公司跟人家要錢，最重要就是發債與發股、舉債與舉股。
- 要賣一張紙，就要知道這張紙值多少錢。
- 這也是融資決策核心。
- 公司想把這張紙賣貴一點。
- 買的人想買便宜。
- 市場永遠是買方和賣方各自看價值，最後形成價值。
- 做投資要看買的東西值不值。
- 財務管理不是投資學的股票投資。
- 財務管理重點是買機器、裝置。
- 買機器裝置是為了盈利、創收。
- 買機器裝置不是投資選擇權、股票、黃金。
- 要知道花錢買機器裝置划不划算。
- 看未來能幫公司創收多少、創造多少現金流量。
- 再與現在要犧牲的資源比較。
- 這是本課本質。
### U. 要求報酬率與資金成本
- 投資人若要求較高報酬，對融資人而言就是較高資金成本。
- 公司為取得 100 元資金，若每年付 5 元或 8 元利息，就是資金成本概念。
- 發股取得 100 元，若每年只需付 2 元，資金成本較低。
- Cost of capital 是資金的成本。
- 若投資人要求 7%，投資人的要求報酬就是 7%。
- 同一筆交易中，公司借到資金後，公司的資金成本也是 7%。
- 要求報酬率與資金成本在同一資產、同一筆交易下是同一個東西。
- 很多學生會被名詞搞混。
- 老師強調這張圖一定要記住：這些名詞都是同一個東西（圖待確認）。
- 最常見混淆是投資人觀點與融資人觀點。
- 投資人觀點：給錢出去、要求回報。
- 融資人／公司觀點：跟人拿錢、要付利息或報酬。
- 老師用 beggar 比喻融資人是請求錢來投資的人。
- 同一交易，一個 R 在兩個人那邊名稱不一樣。
- 不要被 RRR、要求報酬、資金成本等名詞 confuse。
- 這部分很重要，學期結束仍可能很多人搞混。
- RRR 要看你是誰：投資人就是要求報酬；公司跟人要錢就是資金成本。
### V. 單筆現金流、Factor 與年金
- 現值、未來值是最簡單的貨幣時間價值概念。
- n 期後未來值，是現在價值乘上 n 次方複利因子。
- 單筆現金流可以用複利處理。
- Factor／因子通常以一塊錢為基準。
- 以前常使用利率因子表，現在較少，但解釋概念仍會用。
- 沒有計算機或考試不能方便使用計算機時，複利 20 次不容易手算。
- 考試會附利率因子表供查表使用。
- 一塊錢在某利率、某期數下的結果可透過表格查出。
- 實際金額 500 元就乘 500。
- 實際金額 325 元就乘 325。
- 實際金額 3,820 元就乘 3,820。
- 因子只限定一塊錢狀況，實際題目金額要按倍數乘上去。
- 年金現值開始是較重要且實務常用內容。
- 年金分有限年金與無窮年金。
- 有限年金收到第 n 期，例如 10 年、20 年。
- 無窮年金是一直拿到永遠。
- 無窮年金會收斂。
- 有限年金要處理期限，反而比較麻煩。
- 無窮年金情境是每年拿 A，拿到無窮無盡。
- 每年固定金額且拿到永遠，折現率為 r，現值是 A / r。
- 無窮年金現值 A / r 一定要記。
- 無窮年金公式是數學標配。
- 年金就是每年都一樣金額。
- 有限年金可用無窮年金角度解釋。
- 若 n 是無限大，公式中某一項最後會變成 0。
- 有限年金本來可視為無窮年金，但後面那段沒有收到，所以減掉後面一段。
- 有限年金公式可記，但 Excel 等工具有現成公式。
- 有限年金公式以後推導會一直用到，例如第八章、第九章（待確認）。
### W. 成長年金、永續成長與股利折現模型
- 成長年金第一年是 C。
- 第二年開始會有一個成長率。
- 成長率固定。
- 成長率固定到永遠。
- 老師提到這種資產存在。
- 老師舉例 consol bond，即永續年金債券。
- 英國有 consol bond。
- 英國在日不落帝國時期認為自己會永遠存在，因此有永續債券背景。
- 永續成長是「一加 g、一加 g」一路平衡成長上去。
- 永續成長讓人聯想到會計中的永續經營。
- 永續成長與公司評價有關。
- 此概念最後會連到 stoSeagate valuation。
- 不成長現金流價值，就是把現金流用折現率 r 折現。
- 一連串現金流折現看起來繁複，可以把 (C/(1+r)) 提出來。
- 折現後面會形成無窮等比級數。
- 級數就是把它加起來，數列就是沒有加起來。

- 若 g = 0，固定成長模型退化成不成長現金流。
- g = 0 時就等於永續年金。
- 只要一個東西有固定成長，成長率越高，價值越大。

### Z. 資本支出、投資案類型與風險
- 接下來談資本支出。
- 支出是 expense。
- 資本支出就是長期支出。
- 資本支出就是長期投資。
- 長期支出是錢花下去後，效益超過一年以上。
- 如果支出效益不到一年以上，就叫費用支出。
- 公司費用支出是今年花完就停止。
- 電費是費用支出。
- 電費追求當期收益／當期效果。
- 電腦是資本支出。
- 買電腦追求當期與未來幾期收益。
- 支出性質可分經常性支出與資本支出。
- 經常性支出追求當期效果。
- 資本支出追求當年以外的未來效益。
- 教室椅子是資本支出例子。
- 如果只談費用支出，就沒有太多未來效益，也沒有折現問題。
- 投資決策主要談資本支出與長期投資。
- 投資的風險來自現金流。
- 講風險時，是指現金流不確定性。
- 任何投資需要承擔的風險，來自現金流不確定性。
- 投資到底賺多少錢是不確定的。
- 判斷案子要不要做，有互斥案與獨立案。
- 互斥案是吃了這個就不能吃那個。
- 選了其中一案，就排斥其他案子。
- 獨立案是這個也不錯、那個也不錯，可以各自判斷。
- 獨立案是否接受某案，只取決於該案好不好。
- 公司決策與日常決策很多都是互斥案。
- 公司實務中很少完全獨立案。
- 選總經理是互斥案。
- 大樓電梯選品牌是互斥案。
- 獨立案常見於錢很多、可以投好幾個案子的情況。
- 投資評估主題包括投資評估兩種觀點、回收期限、淨現值法。
- 回收期限聽起來簡單，但有很深的東西。
- 淨現值法理論上最好的方法。
- 淨現值法有很多 bug。
- 淨現值法重要，因最容易跟利害關係連結。
- 股東會或董事會可說去年替股東創造 30 億價值。

### AB. 現金流入、流出與分開折現
- 投資計畫會有現金流入（inflow）與現金流出（outflow）。
- 買機器設備多半為了創造收入。
- 創造收入過程一定伴隨費用與成本。
- 實務上通常會把 inflow 與 outflow 相減。
- 相減後稱為 net cash flow。
- 現金流量圖中箭頭方向代表流入或流出。
- 實務上看 net cash flow 很直覺，但理論上有問題。
- 教授提醒思考：為什麼 inflow 與 outflow 可以直接相減。
- 相加或相減現金流，代表承認每一塊錢在現在角度下等值。
- 若一年後承諾給兩筆 100 萬，可相加成一年後 200 萬，前提是兩者風險等值。
- 兩個現金流相加後再折現，隱含使用相同折現邏輯。
- 收入與支出的風險不一定相同。
- 不同風險現金流直接相加或相減，是理論 bug。
- 實務上仍常把所有收入與支出相減得到 net cash flow。
- 若風險差異不大，實務估計本來有誤差，差一點可接受。
- 若現金流風險差異重大，就應分開處理。
- Excel 中分開折現很容易，只要分成多條現金流、多排計算。
- 教授說現行實務常把所有東西混成一鍋粥。
- 運輸業支出可能包括人事與油料。
- 運輸量與油價不一定呈固定關係。
- 油價高低與運輸量可能相關、反向或不明確。
- 一個投資可能有多種收入來源。
- 飯店收入不只有住宿收入。
- 飯店還可能有餐飲收入、其他收入、特殊租金等。
- 不同飯店收入來源風險不一定相同。
- 做餐飲不見得很好，風險與住宿不同。
- 來吃飯的人與住宿的人不同，受到影響也不同。
- 若一個計畫有兩種收入，一種來自股票、一種來自現金，兩者風險不同，不應直接加總。
- 相加不同風險現金流，等於承認兩個一塊錢都是等值。
### AC. 高鐵案例：固定成本、風險與政府觀點
- 高鐵每年要給政府營運權租金，老師提到 36 億。
- 高鐵營運權租金不管有沒有營運都要支付。
- 老師提到期間為 30 年。
- 營運權租金是合約講好的固定金額。
- 財務上的風險指現金流是否確定。
- 若 36 億確定非給不可，就沒有營運收入那種不確定性。
- 確定支付的現金流應用無風險利率或較低折現率折現。
- 高鐵案當時折現率老師提到約 10 個點。
- 當時無風險利率約 5.4%（待確認）。
- 票款收入、運費等有風險收入應用較高折現率。
- 固定營運權租金不應與票款收入混在一起用同一高折現率折現。
- 若 36 億固定成本用 10% 折現，而本應用約 5.4% 折現，成本現值會變小。
- 成本現值變小會造成投資計畫價值被高估。
- 遇到風險差異大的案子要分開算。
- 決策者若認為有必要分開算，應要求同仁分開折現。
- 分開折現可將收入多列、成本多列，最後各自折回現在。
- 同學問高鐵支出若寫在合約裡是否確定。
- 同學認為合約仍可能違約，因此是風險。
- 講者指出討論是在計畫評估階段，還沒開始做、也還沒招標。
- 高鐵案有條款：經營不善、不賺錢時，可以脫手或賣出，且可用成本價。
- 從高鐵營運方／投標方角度，若能成本價賣回或移轉，風險很低。
- 風險要先界定是誰的風險。
- 從政府角度，風險不只是 36 億。
- 政府更大風險是高鐵做不好，無法達到服務大眾、社會福利目標。
- 政府更在乎系統能否正常營運下去。

### AD. 債權人與股東觀點
- 很多大學課程先教投資決策，再教融資決策。
- 因還沒教負債，教投資決策時通常假設公司沒有負債。
- 無負債情境下，投資評估多以股東價值或市場價值最大化為主。
- 若有舉債投資，評估觀點變成兩套：債權人觀點與股東觀點。
- 投資計畫在董事會通過前尚未執行。
- 在舉債投資時，錢還沒借到前，銀行不是公司的債權人。
- 公司向銀行借錢時，銀行會要求看投資計畫。
- 公司不能只對銀行說希望股東價值最大。
- 債權人關心債權保障最大。
- 債權人與股東天生有利益衝突。
- 債權人願意借錢，前提是投資計畫要符合債權人規矩與標準。
- 董事會或公司在舉債投資時要同時照顧債權人與股東。
- 先搞定債權人，因為借不到錢就不用算股東價值。
- 銀行最關心還本付息。
- 長期負債可能要持續很多年還本付息。
- 債權人關心每一期是否能還本付息。
- 債權人關心每期現金流入是否能 cover 要支付的本息。
- 教授強調是本息，不是只有利息。
- 寬限期可能第一年不用還本，第二年開始還本。
- 只看利息保障倍數不夠，因本金也可能付不出來。
- 債權人看 debt service coverage，而不是單純 interest coverage。
- 還本付息需要充足現金流量。
- 現金流量應來自該計畫營運現金流。
- 不能到期時再向另一家銀行借錢來還本付息。
- 若計畫營運現金流無法 cover 本息，計畫本身不好。
- 剛好 cover 債權人也不一定滿意，還要有安全邊際。
- 銀行會看計畫書與現金流推估是否合理。
- 投資計畫不能胡說八道假設每天滿載。
- 高鐵運量估計要考慮離峰、尖峰、平日、週末差異。
- 銀行第一件事看 operating cash flow。
- 銀行也會關心資產是什麼擔保。
- 債權人重視擔保品保障。
- 債權人希望擔保品價值上升，不希望下降。
- 擔保品價值越做越高，債權人越安全。
- 債權人關心整個資產價值。
- 債權人對資產有優先請求權。
- 債權人不論對資產本身或資產產生的現金流，都有優先請求權。
- 營運現金流要優先支付債權人。
- 債權人拿走本息後，政府也會拿稅。
- 股東拿剩下的現金流。
- 股東拿稅後現金流中剩餘可分配部分。
- 股東是剩餘請求權人。
- 股權投資人若要求現金股利，會關心公司現金流夠不夠付錢。
- 股東關心自己可以分到的 cash flow。
- 股東也關心股權價值是否上升。
- 若投資 10 塊配一股，最後變 5 塊，股東不開心。
- 債權人看資產與償債安全，股東看股權價值與剩餘現金流。
- 資產價值上升代表資產報酬率大於要求報酬率（符號待確認）。
- 股權價值上升代表 ROE 大於股東要求報酬率。
- 若 ROE 大於要求報酬率，股權價值會增加。
- 價值增加意思是比股東自己做更好。
- CEO 有價值原因，是幫股東賺得比股東自己能賺更多。
- 股東自己可以賺到的是要求報酬率。
- 投資報酬率必須大於股東自己可賺報酬率，才有增加價值。
- 股東不是完全不關心整體計劃或債務。
- 只要公司付不了債，股東可能一無所有。
- 股東也會關心公司會不會違約、付不了債。
### AE. 回收期法與設定年限
- 回收期法基本直覺是看投資多久能回收。
- 例子：投資 100 萬，第一年回收 30，第二年 30，第三年 40。
- 30 + 30 + 40 = 100，不考慮折現時三年回收。
- 不考慮折現的回收期就是直接累計名目現金流。
- 考慮折現時，要把第一年、第二年、第三年收進來的錢折現到現在。
- 折現回收期與不折現回收期差別在是否折現。
- 兩個投資計畫只能挑一個，一個 29 年，一個 31 年。
- 回收期直覺上選較短，因越長風險越多。
- 但 29 年與 31 年都太久，可能兩個都不選。
- 29 年期間內人可能都換了很多任。
- 投資計畫通常會先設定超過幾年就不做。
- 設定年限是投資計畫評估非常關鍵變數。
- 不能只學越短越好，實務上還要看設定年限。
- 若兩案都超過設定年限，不能因其中一個較短就接受。
- 若對未來環境樂觀，且經濟或政治系統穩定，設定年限可拉長。
- 若系統不穩定，經濟狀態不穩定，投資者不敢放太久。
- 「日久就生變」：時間越長，不確定性越多。
- 環境越穩定，越願意承擔較長期間。
- 風險越小，可以忍耐越長時間。
- 設定年限會因投資地點不同而不同，例如臺灣或大陸。
- 資源民族主義與國有化風險會影響設定年限。
- 礦產投資可能因國有化或限制而無法 cover 投入。
- 美國在拜登時代對台積電、三星等投資也有限制。
- 在美國投資可能也要設定最長不能超過 10 年，因情況會變。
- 企業常說超過三年不做、超過五年不做。
- 設定年限因素之一是產品生命週期。
- 若產品生命週期不可能超過三年，就不能期待超過生命週期後才回收。
- 設定年限與專案可能創收年限有關。
- 設定年限可能受特許年限限制。
- 若特許年限五年或六年，就必須在特許年限內回收。
- 新藥投資若藥證／專利期間最多 15 年，就不可能預期超過 15 年後才回收。
- 專利期間後可能有學名藥、生物相容性藥競爭。
- 即使在藥證或專利期間內，也可能有其他新藥出現。
- 設定年限可能與政治制度有關，例如書記任期、政策支援是否延續。
- 一旦決定可接受設定年限，如五年、六年、三年，後續分析都受影響。
- 做 NPV 前要先決定算到第幾年。
- 若 N 設成三年，就只能算前三年。
- 若明明認為五年以後不接受，就不應該還算到七年。
- 回收期限設定年限決定後續所有分析中的 N。
- IRR 中的 N 也會跟著設定年限。
- 最後一年除了營運現金流量外，實務上通常要假設把計畫、公司或資產賣掉。
- 最後一年可估計五年後賣價。
- 老師稱之為 X。
- X is the value, or price。
- X 是出場時可得到多少 cash。
- 最後資產要處分掉。
- 若是一個公司或投資計畫，可以像公司一樣賣掉。
- 即使投資者不願三年後繼續經營，該公司或計畫仍可能繼續創造營運現金流。
- 規劃時要預想萬一那時候賣掉，價錢是多少。
- 最後一年現金流要包含營運現金流與 exit price。
- 若設定年限為六年，兩個互斥案一個三年回收、一個五年回收，從回收期角度選三年。
- 回收期本身就是風險指標。
- 三年回收代表三年後價值已回來。
- 六年回收代表承擔六年風險。
- 企業可用回收期控制風險，例如控制在五年、四年、三年。
- 大陸改革開放初期，臺灣傳統產業到大陸投資，回收期常壓在一年內。
- 當時制度不健全、人事因素濃厚，環境非常不確定。
- 一年賺回來後，剩下都是多賺。
- 高風險環境會要求極短回收期。
### AF. NPV 基本邏輯與現金流口徑
- NPV 是未來各期淨現金流量的現值。
- NPV 邏輯是期初投資，期末第一期、第二期、第三期現金流回收。
- 把所有未來現金流折現回來，看能否 cover 初始投入。
- 未來現金流包括一年後、兩年後、三年後等。
- 初始現金流是零期，也就是現在。
- 理論上，現值加總要大於初始投入。
- 若現值加總大於初始投入，表示價值增加。
- NPV 大於 0 才表示投資案創造價值。
- 不是所有投資計畫一開始都一定是現金流出。
- 有些投資計畫一開始可能有流出，也可能有流入。
- 現金流可能先流入、再流出、再流入。
- 各種現金流量狀態都有可能。
- 現金流入不一定容易，要靠業務把東西賣出去。
- 花錢看似容易，但實務上花錢也可能很困難。
- 美國蓋紀念堂，100 億美金也可能很難花。
- 西直門蓋館約 5–6 億，也因設計、校長更替、重選建築師、招標等問題很辛苦。
- 花錢與賺錢都很急，都是創造價值過程中需要付出的 effort。
- 如果投資計畫生產裝置做得不好，將來不會生產出好東西。
- 前面的規格設定很煩但很重要。
- 買椅子也需要比較哪種椅子好、坐久是否不髒、顏色是否耐髒。
- 支出端細節會影響後續收入與價值創造。
- 招生、吸引學生報名也是收入端不容易部分。
- 評估 cash flow 時，inflow 與 outflow 同樣重要。
- 不能只認為 inflow 重要，outflow 也很重要。
- 較好的 NPV 定義要把整個評估期間的收入與支出全部列入。
- 支出是負的，收入是正的。
- 所有收入與支出合在一起，最後結果為正代表增加價值。
- NPV 為零代表忙半天「南柯一夢一場空」。
- NPV 為負代表比原來情境更差。
### AG. Project cash flow、Equity cash flow、RA、RE 與 IRR
- 投資計畫資產為 100。
- 題目中負債為 40。
- 題目中股權為 60。
- 淨現值有兩種觀點。
- 第一種是整個投資計畫能否增加價值。
- 第二種是股東投資能否增加價值。
- 若要算計畫有沒有增加價值，就要算投資計畫增量價值。
- 若是計畫觀點，投資多少就是 100。
- 計畫觀點下 CF0 是 -100。
- 初始投資是 outflow，所以寫負數。
- 若算股權淨現值，也就是股東淨現值。
- 股東投資多少就是 60。
- 股權觀點下 CF0 是 -60。
- 如果 CF0 是 -100，後面現金流量要配計畫／資產觀點。
- CF0 是 -100，代表算資產的淨現值。
- 資產現金流量不應扣掉利息。
- 扣掉利息代表扣掉債權人拿到的錢。
- 若已扣掉債權人拿到的錢，就不再是整體資產現金流。
- 資產 cash flow 不扣利息。
- 如果 CF0 是 -60，表示從股東觀點看。
- 股權觀點下，債權人先取得利息／還本後，才輪到股東。
- 股權 cash flow 會反映扣掉債權人後剩給股東的現金流。
- 如果 CF0 是 -100，折現率應用 RA。
- CF0 = -100 對應資產現金流。
- 資產現金流要用資產風險或資產折現率 RA。
- 如果 CF0 是 -60，折現率應用 RE。
- CF0 = -60 對應股東現金流。
- 股東現金流要用股東風險折現。
- 股東現金流不能用資產要求報酬率折現。
- 讀報告不是要自己全部重算。
- 重點是看報告到底算哪個觀點。
- 要檢查報告方法是否弄錯。
- 如果連方法都弄錯，就不要繼續看。
- 當主管要能發現報告方法錯誤。
- 投資案報告通常很厚、很討厭。
- 要想辦法三分鐘先找出方法錯誤。
- 權益觀點下，各期現金流是股東各期現金流。
- 計畫觀點下，各期現金流是計畫各期現金流。
- 老師使用 project cash 與 equity cash 區分。
- 股權現金流與資產現金流最大差別不只在利息。
- 最容易看的判斷點是有沒有扣掉利息。
- 有扣掉利息，代表債權人已取得債權相關支付，剩下是股東部分。
- 沒有扣掉利息，代表還沒扣債權人利息，屬於資產現金流。
- 如果 cash flow 有扣掉利息，一定是股權現金流。
- 股權現金流對應 RE。
- 如果 cash flow 沒有扣掉利息，屬計畫／資產現金流。
- 計畫／資產現金流對應 RA。
- 逐字稿中有一句「如果沒有扣掉利息的話，這邊就是 re」疑似口誤或轉錄錯誤，依前後文應為 RA（待確認）。
- IRR 也有類似觀點問題。
- IRR 形式與 NPV 類似，也有 CF 影響。
- 算出來的報酬率是 RA 還是 RE，要看現金流口徑。
- 如果 CF0 是 -100，算出來偏 RA。
- 如果現金流有扣掉利息，算出來偏 RE。
- 判斷 IRR 時，也要先看是資產現金流還是股權現金流。
- 實務報告常常亂。
- 學會兩種觀點，就贏過很多大學生財務基礎。

- 過去可能因一堆不清楚資產或股票而被市場折價。

- 兩階段總結：第一階段賣掉營運資產，第二階段清洗所有不必要、多餘、可能影響評價的資產。
- 最後 Seagate 投資組合非常乾淨：現金加股票。
- Veritas 股票不能直接在市場上賣掉，而是透過交換清理資產。
- 所有資產交易中，最容易引起稅務機關注意的是資本利得。
- 賺資本利得就要繳稅。
- 股權交換通常是等價交換。
- 在等價交換過程中，基本上沒有所謂稅。
- 持股換新股基本上沒有現金收付問題。
- 若賣掉股票，會有現金與原始成本價值差額，形成課稅問題。
- 實際稅務仍要看各國稅法。
- Super LBO 與某投資方找到一條股權交換過程中不被課稅的安排（待確認）。
- 本案透過多個步驟，基本上為了免去證券交易過程的稅。
- 第二階段存在，就是為透過股權交換避免稅務問題並進行清洗。
