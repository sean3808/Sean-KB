# 07-12 課程：PMBA 財報分析與營運現金流量評估

### 1) 🎯 本次學習快照（30 秒看懂）
- **課程／章節**：PMBA 財報分析與投資決策 / 財務管理與報表分析
- **本段主題**：會計原則與假設、現金流量表判讀、營運資金管理（CCC）、財務比率分析與企業價值評估、TEJ 資料庫操作。
- **一句話收穫**：財報數字易受會計方法與歷史成本扭曲（如獲利不等於現金），評估企業真實體質與流動性必須重視「營運現金流量」與「現金轉換循環（CCC）」。
- **關鍵名詞（中英並列）**：繼續經營假設 (Going Concern Assumption)、權責發生制 / 應計基礎 (Accrual Basis)、營運現金流量 (Operating Cash Flow, OCF)、現金轉換循環 (Cash Conversion Cycle, CCC)、共同比 (Common-size ratio)、歷史成本 (Historical Cost)、市價淨值比 (PBV / Price-to-Book Ratio)。
### 2) 🧠 核心概念與框架（Concepts → Structure）
- **框架 / 模型**：
  1. **資產價值的三種層次**：賬面價值 (Book Value，未攤銷歷史成本)、重置價值 (Replacement Value，現時市價)、營運價值 (Operating Value，未來現金流折現)。
  2. **三大報表與數據性質**：資產負債表是特定時點的**存量 (Stock)**；損益表與現金流量表是一段時間的**流量 (Flow)**。
  3. **企業金流三部曲**：向外融資 (Financing) $\to$ 進行資本支出/投資 (Investing) $\to$ 創造營運現金流量 (Operating)。
  4. **財務比率六大分類（企業體檢）**：共同比（整體結構）、營運能力/活動力（進出貨活力）、流動性（短期資金調度）、長期償債能力、獲利能力、市場基本面比率。
  5. **現金轉換期 (CCC) 的 3 大驅動因素**：存貨天數（受採購與製造流程影響）、應收帳款天數（對顧客議價能力）、應付帳款天數（對供應商議價能力）。
- **重要定義**：
  - **繼續經營假設 / 成本原則**：假設企業永久經營，資產入賬是為了「營運使用分攤」，故採用確實發生過的「歷史成本」而非當前市價。
  - **投資效率**：有實質效益的投資，在投入資本支出 (CAPEX) 後，營運現金流量 (OCF) 必須跟著往上走。
  - **早收晚付鐵律**：營運資金管理的理想狀態，錢沒進來就是壞事（獲利不等於現金）。
- **常見混淆點**：
  - **容易搞錯的是「收入＝收到現金」**：依據權責發生制，只要交易完成、權責釐清即可認列收入，與是否收到現金無關。
  - **容易搞錯的是「應付帳款減少是好事」**：在財報解讀上，「付錢付得快」代表喪失延遲付款的談判優勢，可能暗示信用受疑或需現金搶貨。
  - **容易搞錯的是「資產負債表比率的客觀性」**：兩家營收相同的公司，若設備購入時間不同，受「歷史成本」影響，算出的負債比或 ROE 會有嚴重誤差。應優先使用「流量（現金流/損益）」來評估。
### 3) 📌 例子與公式（Examples / Equations / How-to）
- **公式或計算步驟**：
  - **存貨週轉率**：
    - 輸入：銷貨成本（損益表）、平均存貨 (上期末+本期末)/2
    - 計算：`銷貨成本 / 平均存貨 = 存貨週轉次數` $\to$ `365 / 週轉次數 = 週轉天數`
  - **現金轉換循環 (CCC)**：
    - 計算：`平均存貨天數 + 平均應收帳款天數 - 平均應付帳款天數`
    - 解讀：現金流出到流回的時間，越短越好（甚至為負代表流動性極佳）。
  - **最強償債指標公式**：
    - 計算：`稅前息前營運現金 / 利息費用（或償債支出）`（註：銀行視角的償債支出 ＝ 當期利息 ＋ 當期還本金）
    - 解讀：完全基於營運創造的現金來評估還錢能力，排除會計誤差。
- **代表性例子**：
  - **臺積電與 ASML 光刻機（賬面 vs 營運價值）**：各廠買機器成本一樣（賬面價值），但臺積電市價淨值比達 20 倍，反映的是其透過人力與生產創造未來現金流的「營運價值」。
  - **電子代工大廠的 CCC（和碩/鴻海/廣達）**：應付帳款遠大於應收帳款，利用「6+1」條款（1個月驗收+6個月寬限期）強勢延遲付款，CCC 極短，手上握有龐大淨現金可供調度。
  - **金融業股價低估（ PBV ）**：金融業擁有早年低價購入的自有不動產，賬面價值本身就被低估，若市價淨值比 (PBV) 又低於 1（如 0.5），代表是極度低估的標的。
### 4) 🧪 可能考點（Exam hooks）
- **高機率考點**：更改「會計方法」（如存貨計價先進先出改加權平均）對哪張報表影響最小？（答案：現金流量表）。
- **高機率考點**：製造業的「折舊與攤銷」要從哪張報表取得？（答案：現金流量表，由淨利往下打並加回，因其隱含在營運成本中）。
- **容易出陷阱**：看到算出來的現金轉換循環（CCC）是「負數」，直覺以為公司資金鏈斷裂。 $\to$ *正確做法：CCC 為負數代表公司拿別人的錢做生意（早收晚付），是流動性極佳的好事。*
- **容易出陷阱**：存貨上升或應收帳款快速增加一定是壞事。 $\to$ *正確做法：存貨上升若是為了預期缺貨打產能則為正常；應收帳款若無市場大單風聲卻暴增且 OCF 為負，才是做假帳的嚴重警訊。*

- 個案相關的財報比率分析、現金流量評價、價值評估會優先講完。
- 提及後續上課與交報告日期：2026-07-16、20 (A班)、25、26 (B班)（註：此為講者口述日期）。
- 複習前三項假設：期間假設、貨幣衡量假設、經濟個體假設。
- 第四項假設：繼續經營假設 (Going Concern Assumption)，假設營利或非營利事業會永遠經營下去。
- 長期資產目的：以經營為目的，非透過買賣套利（低進高出）。
- 資產入賬觀點：不關注目前市值/可賣多少錢，而是關心其能為公司創造多少營收，以及在期間內如何分攤成本 (Cost)。舉例：40塊買入電腦，用4年，年底財報顯示30（未攤銷成本）。
- 成本原則：資產入賬只關心歷史成本 (Cost) 而非市值。因為成本具備可靠性。不隨聽說的市值漲跌而調整。
- 充分揭露原則：將公司資訊揭露給利害關係人。
- 充分揭露與貨幣衡量原則的互補：若某事很重要但無法用貨幣衡量具體數字（如法律訴訟、併購案風險），仍須透過財報附註等方式揭露。
- 補充閒聊：提及近期海運公司併購或拆分案的法律追溯期（20年），說明資訊揭露不足的風險；併購案揭露的兩難（揭露後破局被控操縱股市，不揭露成功後被告）；企業經營過程中法律的關鍵性（保密協議等）。
- 收入承認原則：承認收入與現金收到沒有直接關係。
- 應計基礎與權責發生制：交易到一個程度，權利與責任清楚才算完成。送貨不等於完成，需經過驗收、試車、規格測試（Performance spec）。
- 費用配合原則：為爭取收入產生/過程中的支出需一併承認。FOB離岸交貨的運費與報關費即使未付現金，也要配合收入認列。
**資產價值與三大報表性質**
- 賬面價值 (Book Value)：財報上看到的數字，尚未攤銷掉的歷史成本；與名目價值、重置成本兩不相沾。
- 重置價值 (Replacement Value)：買相同新舊資產的目前市場價格 / 目前的市值。
- 營運價值 (Operating Value)：營運創造的未來現金流折現反映的價值。
- 舉例：臺積電市價淨值比約 20 倍。淨值 = 賬面價值 (1)；市價 = 營運價值 (20)。
- 股權估值概念：資產價值扣掉負債 = 股權估值。
- 學生提問：臺積電專利權屬於哪種價值？教授回答：專利權在財報上只顯示投入成本（賬面價值），但其反映在股價上的是營運價值。重置價值對專利權較無意義。
- 舉例：ASML光刻機每台成本一樣（賬面價值），但不同公司創造的營運價值不同。
- 估值情境：營運好的公司看營運價值；連年虧損快倒閉但有房地產的公司看重置價值。
- 損益表上看到的費用不代表真實現金支出（銷貨成本、銷售費用、折舊攤銷、利息費用不一定是現金支出）。稅後淨利（如258,000）不等於創造的現金流。
- 財務人員視角：No cash, no value。
- 重資產與輕資產的財務負擔差異（土地例外不折舊）。
- 資產負債表是特定時點（如12/30）的水位，屬存量（Stock base data），瞬時可變。
- 損益表是一段時間的累積，屬流量（Flow data）資料。流量資料在統計上較穩定。
- 現金流量表為時段資料，屬流量資料。1988年美國會計準則協會發布準則，以現金流量表取代原有的財務狀況表，因應1980年代初歐美的「黑字倒閉」。
**現金流活動與營運資金管理**
- 現金流量表三大分類：經營（營運）活動、投資活動、融資（籌資）活動。
- 資產負債表右側的負債與股權變動等同融資活動（債務增加＝現金流入；債務減少＝還錢；減資/發現金股利＝現金流出）。
- 融資的目的是為了投資；投資的目的是為了營運創收。
- 市場對於營收同比增加有反應，受行為財務/市場情緒 (sentiment) 影響。
- 營收只是帳面數字，營運現金流量 (OCF) 才是最接近真實價值的指標。
- 資本支出增加，代表對未來景氣看好（如 AI 資料中心的新增）。董事會確認下一年度資本支出（約在第三季）。
- 買賣業/服務業在損益表有清楚的折舊攤銷科目；製造業的折舊攤銷會被分入營運成本或營運費用，必須在現金流量表尋找。
- 現金流量表算法：從淨利往下，將無真實現金流出的折舊攤銷加回（舉例：台積電 2022 年折舊 4280 億、無形資產攤銷 87.56 億）。
- 財報標準觀察期為五年。
- 地雷公司財報特徵（國達、迅捷）：不斷向外融資並大量投資，但投資後營運現金流量沒有改變（船過水無痕）。會計師不願簽署或出具保留意見，導致下市。
- 現金流是最難做魔術調整的指標，會計師願簽字代表具一定真實性。
- 正常公司的現金流特徵：有季節性（如 Q2/Q3 備庫存影響短期現金流），但年度四季加總的營運現金流量穩定向上（如鴻海）。
- 電信業大額投資（5G設備 500億）：觀察為支應大額投資向外融資的比例。口袋深度的定義：需要對外借多少錢 vs 自身有多少現金。
- 投資有效率的定義：資金投入後，營運現金流能隨之上昇。
- 投資學的好標的定義：股價被低估的公司（好公司不代表好股票，股價過高買了會虧損）。
- 應收帳款上升本身通常不是好事（錢沒收回）。正常的增加：市場競爭激烈放寬付款條件。異常的增加：有問題的公司做假帳膨脹 sales（往往看起來沒問題掩飾很好）。
- 看到應收帳款快速上升的第一步：了解有沒有接到大單的市場風聲。任何營收突然爆出來，有問題的公司「一定」有這現象。
- 國寶案例：應收帳款從10億暴增到30、35億，一年sales沒收回且OCF為負。另有半年報應收從20億增到近100億未面對問題案例。
- 獲利增加應該與現金流增加方向相同。背離原因 1：應收帳款變多收不回來；原因 2：應付帳款減少，付錢付太快。
- 應付帳款減少的負面原因：供應商不放心信用、市場缺貨需現金調貨。市場馬上會傳出跳票風聲。
- 應收帳款慢慢上升會給市場充滿樂觀的錯誤訊號。
- 營業外收入增加（如處分資產）或毛利率增加：獲利增加但營收沒增加的原因。
- 警訊：大股東申報持股轉讓、關係人交易頻繁。
- 應付帳款大於應收帳款代表：還沒付出的錢多，留在手上的淨現金多（好公司指標，如代工廠差額75億可放定存）。做生意原則：早收晚付。
**會計方法影響與財報分析注意事項**
- 財報編制按照會計準則，各國容許好幾個方法。跨公司比較時要確認會計方法是否一致。
- 主管需請同仁評估A法/B法會高估還是低估。
- 更改會計方法對「現金流量表」影響通常不大（現金流最乾淨）。對應計基礎的「損益表」與「資產負債表」有影響。
- 同一家公司改會計方法財報數字會跳動，通常會重編前三年，這種跳動不重要。
- 存貨計價方式（先進先出、後進先出）會影響資產負債表存貨數字及銷貨成本、存貨週轉率。
- 折舊方法（如加速折舊）會較早影響獲利數字，是損益表指標中唯一會造成兩家公司比較差異的因素。
- 建築業完工利潤入帳方法（完工法或成本回收法）會影響營收與淨利。
- 董事會往往更喜歡看損益表、EPS 與比率分析，而非現金流量表。
- 注意事項二：不尋常的存貨上升（存貨上升是中立指標。正常：Sales增帶動存貨增；缺貨打產能。不尋常：Sales沒增存貨升）。
- 注意事項三：不尋常的應收帳款上升（最重要打星號。中性指標。出問題公司的共同特徵，但快速上升不代表一定有問題）。
- 提醒財報數字差異是公司內部編表同仁責任，會計師通常獨立簽字（除非付費聘管顧）。兩位老師沒有會計師資格。
**財務比率分析與流動性評估**
- 財務比率六大分類：共同比、營運能力（活動力）、流動性（心肌梗塞致命）、長期償債能力（熬夜體質）、獲利能力、市場基本面比率。
- 共同比分析 (Common-size Ratio)：像照 X 光。資產負債表以總資產為分母（檢視資產/融資結構，如存貨佔25%現金少影響流動性；無形/變現資產低於同業為負重賽跑）。損益表以銷售收入為分母（看毛利、費用、折舊、利息佔比；折舊低代表營運槓桿輕）。
- 平均存貨 = (上一期年底存貨 + 這一期年底存貨) / 2（靜態平均，未考慮淡旺季）。
- 存貨週轉率 = 銷貨成本 / 平均存貨。存貨週轉率並非越高越好（過高會導致缺貨）。
- 存貨模型：持有成本與存貨量正比；缺貨成本與存貨量反比。目標找最適水準。若缺貨容忍度低（客戶無法等）最適存貨水準需提高。需與產業平均比較（如平均20次，做到150次太誇張）。
- 應收帳款週轉舉例：營收2000萬，平均應收200萬，轉10次，約36.5天收回。天數越短越好。
- 預收帳款為負向概念，錢越早進來越好。
- 固定資產週轉率缺陷：受歷史成本影響極大，老公司資產成本低會導致比率虛高。評估經營效率較佳指標：營運費用 / 營業收入（無歷史成本問題）。
- 短期償債能力：流動比率 = 流動資產 / 流動負債；速動比率 = (流動資產 - 存貨 - 預付款項) / 流動負債（扣除變現慢科目）。
- 傳統流動性指標（存量）缺陷：年報12/31數字具時間滯後性，且存量不可靠。
- 流量流動性分子：期初現金與有價證券 + 營運創造現金；分母：年底流動資產（未來一年應付款）。
- 還款現金來源：處分資產、借新還舊、向股東要錢、營運賺到的錢（最好）。
- 營業迴圈天數公式：存貨天數 + 應收帳款天數。
- 現金轉換循環 (CCC) 長度公式：平均存貨天數 + 平均應收帳款天數 - 平均應付帳款天數。越短越好，甚至可為負。傳統產業看流動性時是非常好的指標。
- CCC 為負產業案例：B2C遊戲產業賣光碟，直接收現無應收，無存貨，對壓片廠可延緩付款（CCC負五塊，代表一直有現金）。
- 會計盈餘與現金流差異案例：玉龍車連三年EPS為負但CCC正常；中華車CCC約1-2個月；國產車賣美國進口車，存貨天數理應短，但買賣業CCC比製造業長，雖有獲利但87年下市。
- 預警指標：製造業CCC超過300350天或同業一倍即有問題。印度市場產業(黃孔/大宇)存貨成本極低不應超150200天。需提早5~6季（一年半）預警，因合約一年一簽。
- 單一指標侷限性：迅捷出事前CCC天數尚可。需多維度綜合判斷。
- 商業模式轉變：中華電信由B2C轉B2B後產生應收帳款，CCC變長(約60天)，是經營模式改變而非變差。
- 大型企業供應商管理：廣達最高80天，平均60-70天。因強勢議價能力，利用「6+1」條款延遲付款。
**長期償債、獲利與市場價值比率**
- 避免用純資產負債表資料分析長期償債能力，歷史成本會扭曲負債比。偏好損益表或現金基礎。
- 營業利益公式：收入 - 營業成本 - 收管 - 折舊攤銷。
- 營業利益 / 利息 = 利息保障倍數。
- 銀行角度：營業利益 / 償債支出 (當期利息 + 當期要還的本金)。
- 推薦現金基礎比率：稅前息前營運現金 / 利息費用(或償債支出)。比 EBITDA 更乾淨，完全用營運創造現金還款。
- ROE 盲點：獲利相同，普通股權益因歷史成本不同導致誤差。銷售基礎比率較準。
- 企業價值三概念：營運價值、重置價值、帳面價值。
- 每股淨值 (PBV) 對金融業尤為重要：金融業包含公允價值金融資產與老舊不動產，不動產帳面價值嚴重低估。案例：淨值16，股價8，PBV 0.5值得投資。
- 評估營運價值最佳指標：股價 / 營運現金流量；次佳：EPS（含業外）。重置價值指標：PBV。
- 銀行其他資產（債券、放款）多非歷史成本而是受壞帳影響。
