# Repo 與 SOFR 是短期美元壓力的溫度計

## 核心想法
回購市場（Repo）是參與者拿手上的債券作抵押、借隔夜短錢的地方，關鍵利率是 SOFR（Secured Overnight Financing Rate）。當大家同時需要現金、手上一堆債券都拿去抵押時，借錢的成本就被拉高；所以 Repo 利率飆升是「水管快要爆」的訊號。 ^claim

## 展開 / 理由
講者給的九月觀察序列（簡報 p13），壓力從公債市場一路傳到政策利率：

公債發行增加 → 交易商庫存上升 → Repo 融資需求增加 → Repo 利率上升 → **SOFR 高於 IORB**（準備金利率）→ SRF（常設回購便利）使用量增加 → EFFR（有效聯邦基金利率）承受壓力

- **殖利率上升 ≠ 流動性危機**：美債殖利率上升本身只是價格變化；只有壓力進入 Repo、並影響到 EFFR，才算真正的流動性危機（簡報 p13）。
- **為什麼看 Repo 不看新聞**：講者說要看美國會不會出事，觀察標的就是回購市場（逐字稿 01:06:45）。
- 名詞：IORB＝準備金餘額利率；SRF＝Standing Repo Facility；EFFR＝Effective Federal Funds Rate。簡報只列縮寫，全名為 AI 補充。
- 限制：本卡是觀察序列，不是門檻值；SOFR 高出 IORB 多少才算異常，本堂未給數字。
